# Contributing

Thanks for helping grow the **Rise of Machine**. The only accepted contribution is adding a new AI tool. Edits, removals, re-orderings, redesigns, or config changes will be closed.

## Scope: AI only

Every tool must be genuinely **AI or ML powered**: AI-first products, LLMs, generative models, agents, or ML-driven features. Non-AI tools are out of scope and will be rejected and closed automatically.

## What you can submit

- **Exactly one new tool entry per PR** in [`src/data/tools.json`](src/data/tools.json).

That's it. Don't touch other files. Slugs, sorting, split files, and search indexes are generated automatically.

## How to add a tool

1. Fork the repo on GitHub, then clone your fork:

```bash
git clone https://github.com/<your-username>/riseofmachine.git
cd riseofmachine
```

2. Create a branch. Name it `add-tool/<slug>` using the tool's slug:

```bash
git checkout -b add-tool/tool-name
```

Branch naming: always prefix with `add-tool/` followed by the lowercased, hyphenated tool name (e.g. `add-tool/banana-ai`, `add-tool/copy-pilot`). One branch per tool.

3. Open [`src/data/tools.json`](src/data/tools.json), find the `content` array for the right category (see list below), and add your entry as a new object in **alphabetical order** within that category:

```json
{
  "title": "Tool Name",
  "body": "Short description under six words.",
  "tag": "Freemium",
  "url": "https://example.com?ref=riseofmachine.com",
  "date-added": "2026-08-02"
}
```

4. Run the checks:

```bash
bun run add-slugs   # generates slug + sorts the category alphabetically
bun run check-data  # validates every entry
```

5. Commit and push:

```bash
git add src/data/tools.json
git commit -m "Add Tool Name"
git push origin add-tool/tool-name
```

6. Open a PR against `main`. **One tool entry per PR.** Submit separate PRs for multiple tools.

## Field rules

| Field        | Required | Rule |
| ------------ | -------- | ---- |
| `title`      | Yes      | Exact product name. Must **not** start with the word `AI`, a number, or a special character. Leading `AI`, numeric, and special chars are stripped automatically. |
| `body`       | Yes      | **5–6 words only.** Factual, no marketing fluff. Ends with a period. |
| `tag`        | Optional | Pricing/status label, e.g. `Free`, `Freemium`, `Paid`, `From $10/mo`. |
| `url`        | Yes      | Must be **HTTPS** and include `?ref=riseofmachine.com`. |
| `date-added` | Yes      | `YYYY-MM-DD`. Use today's date. |
| `slug`       | No       | **Do not add or edit slugs.** They are auto-generated by `add-slugs`. |

The URL `ref` parameter is mandatory. If the URL already has query params, append `&ref=riseofmachine.com`.

## Ordering

Entries in each category's `content` array are **alphabetical by `title`**. Insert your tool in the correct position. `bun run add-slugs` will normalize order, but submit it sorted to keep diffs clean.

## Categories

Add to one of the existing categories only:

`art`, `audio`, `code`, `copywriting`, `design`, `developer`, `education`, `enterprise`, `fashion`, `gaming`, `health`, `legal`, `llm`, `music`, `nocode`, `photos`, `productivity`, `prompts`, `research`, `seo`, `social`, `video`, `xtras`

Pick the single best fit. **If you're unsure which category applies, add it to `xtras`.** Don't create new categories.

## Acceptance bar

- The tool is genuinely **AI/ML powered**. Non-AI tools are closed automatically.
- The tool is live and reachable.
- No duplicates. Check the category before adding.
- `bun run check-data` passes with no errors.

PRs that fail validation, add fluff, or modify anything beyond a new tool entry will be closed without merge.
